3. Dictionnaire des codes

Collections
Format : CODE=Nom|mots-clés
Modèles
Format : COLLECTION:NUMÉRO=Nom|mots-clés
Exemple : ODY:1=Maxi Hobo|maxi
Matières
Format : 01=Leather|cuir
Couleurs
Noir et blanc inclus : NO, BL
Hardware
Format : S=Silver|argent

Important : pour ajouter une future collection, ajoute d’abord son code dans Collections, puis ses modèles dans “Modèles”. Exemple : NEW:1=Bucket Bag|bucket.
